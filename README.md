# RTMP ストリーミング実装 (Go)

ffmpegに一切依存せず、**RTMP (Real-Time Messaging Protocol)** をGoでゼロから実装したライブラリ。
プロトコルの各レイヤーに日本語コメントと解説ドキュメントを添えており、
「読みながらRTMPの仕組みを理解する」ことを目的としている。

## このプロジェクトでできること

- RTMP サーバーを起動して、OBSなどの配信ソフトから映像・音声を受信する
- 受信したストリームをFLVファイルに録画する
- 受信したストリームを視聴クライアントにリアルタイム中継する（簡易CDN）
- FLVファイルを読み込んでRTMPサーバーに配信する
- 上記すべてを **ffmpegなし・外部依存なし** で行う

## クイックスタート

### 前提条件

- Go 1.21 以上

### ビルド

```bash
go build ./...
```

### サーバーの起動

```bash
# 基本的な起動（ポート1935 = RTMPデフォルトポート）
go run ./cmd/server

# FLV録画を有効にして起動
go run ./cmd/server -save ./recordings

# カスタムポートで起動
go run ./cmd/server -addr :1936
```

### OBSからの配信

1. サーバーを起動する
2. OBSを開く → 設定 → 配信
3. サービス: **カスタム**
4. サーバー: `rtmp://localhost:1935/live`
5. ストリームキー: 任意の文字列（例: `mystream`）
6. 「配信開始」をクリック

### FLVファイルの配信（クライアント）

```bash
# FLVファイルをサーバーに送信（リアルタイムペースで配信）
go run ./cmd/client -file video.flv

# オプション指定
go run ./cmd/client \
  -addr localhost:1935 \
  -app live \
  -key mystream \
  -file video.flv
```

### テスト

```bash
# 全テスト実行
go test ./... -v

# 特定パッケージのテスト
go test ./pkg/amf0/ -v
go test ./pkg/chunk/ -v
```

## RTMP プロトコルの全体像

RTMPは以下の4つのレイヤーで構成されている:

```
┌─────────────────────────────────────────┐
│  アプリケーション層                       │
│  (connect, publish, play, メディアデータ) │
├─────────────────────────────────────────┤
│  メッセージ層                            │
│  (プロトコル制御, コマンド, 音声, 映像)    │
├─────────────────────────────────────────┤
│  チャンクストリーム層                     │
│  (メッセージの分割・多重化・ヘッダ圧縮)    │
├─────────────────────────────────────────┤
│  ハンドシェイク                           │
│  (バージョン合意, 接続確認)               │
├─────────────────────────────────────────┤
│  TCP                                     │
│  (信頼性のある通信基盤, ポート1935)        │
└─────────────────────────────────────────┘
```

### 接続確立から配信までのシーケンス

```
クライアント(OBS等)                        サーバー
    │                                       │
    │  ① TCP接続                            │
    │======================================>│
    │                                       │
    │  ② ハンドシェイク (C0C1 → S0S1S2 → C2) │
    │<=====================================>│
    │                                       │
    │  ③ connect("live")                    │
    │======================================>│
    │  ④ _result(成功)                      │
    │<======================================│
    │                                       │
    │  ⑤ createStream                       │
    │======================================>│
    │  ⑥ _result(streamID=1)               │
    │<======================================│
    │                                       │
    │  ⑦ publish("streamkey", "live")       │
    │======================================>│
    │  ⑧ onStatus("Publishing")            │
    │<======================================│
    │                                       │
    │  ⑨ 音声・映像データの連続送信          │
    │======================================>│
    │  ⑩ (FLV録画 / 視聴者に中継)           │
    │                                       │
```
