# RTMP ストリーミング実装 (Go)

ffmpegに依存せず、RTMPプロトコルをゼロから実装したGoライブラリ。
各コンポーネントに日本語コメントを付けて仕様と役割を記録している。

## プロジェクト構成

```
rmtp/
├── pkg/
│   ├── amf0/          AMF0エンコーダ/デコーダ（コマンドのシリアライズ形式）
│   ├── handshake/     RTMPハンドシェイク（C0/S0, C1/S1, C2/S2）
│   ├── chunk/         チャンクストリーム層（メッセージの分割・多重化）
│   ├── message/       メッセージ層（プロトコル制御・コマンド・メディア）
│   └── flv/           FLVファイル読み書き（録画・再生用）
├── server/            RTMPサーバー（受信・中継・録画）
├── client/            RTMPクライアント（配信）
└── cmd/
    ├── server/        サーバー起動プログラム
    └── client/        クライアント起動プログラム
```

## 使い方

### サーバーの起動

```bash
# 基本的な起動（ポート1935）
go run ./cmd/server

# FLV録画を有効にする
go run ./cmd/server -save ./recordings

# カスタムポートで起動
go run ./cmd/server -addr :1936
```

### FLVファイルの配信（クライアント）

```bash
go run ./cmd/client -file video.flv -addr localhost:1935 -app live -key streamkey
```

### OBSからの配信

1. サーバーを起動
2. OBSの設定 → 配信 → サービス: カスタム
3. サーバー: `rtmp://localhost:1935/live`
4. ストリームキー: 任意の文字列

## テスト

```bash
go test ./... -v
```

## プロトコル概要

RTMPは以下のレイヤーで構成される:

1. **TCPトランスポート** - 信頼性のある通信基盤
2. **ハンドシェイク** - バージョン合意とRTT推定
3. **チャンクストリーム** - メッセージの分割・多重化・ヘッダ圧縮
4. **メッセージ** - プロトコル制御、コマンド（AMF0）、音声/映像データ
